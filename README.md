# product-website

This is a modern product landing page website for AstraFlow, created as a static HTML/CSS/JS site.

## Files
- `index.html` — website structure and content
- `styles.css` — styling and responsive layout
- `script.js` — mobile menu behavior and footer year

## Run locally
Open `index.html` in a browser, or serve it with a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
